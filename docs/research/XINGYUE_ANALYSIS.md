## 1. 核心研究结论摘要

通过对官方入口及前端核心生产代码的深入剖析，确认星月写作的核心生产力支柱是**“高度模块化的小说创作工作流引擎 (Workflow Engine)”**结合**“设定集资产动态关联机制”**：

1. **工作流系统贯穿全流程**：
   - 包含创建、编辑、列表、运行、单步执行、成组批量执行以及测试 7 大环节；
   - 创作步骤支持自定义标题、占位提示、输入选项与变量输出；
   - 步骤间通过声明式变量引用（`{{前面步骤的变量}}`）实现数据无缝交接。
2. **设定与上下文显式关联**：
   - 彻底解决了普通聊天工具“设定容易漂移遗忘”的通病；
   - 允许作者在任意步骤显式勾选关联【角色档案】、【世界观词条】、【历史章节正文】与【备忘录】。
3. **分步可控的人机协同体验**：
   - 支持“一键全自动连贯执行”与“分步人工审查推进”；
   - 允许作者在每一步完成后直接在卡片内【编辑输出结果】，将用户修改后的内容流转给下一步；
   - 遇到故障支持【从失败处继续执行】，已生成的上游输出完全保留。

## 2. 对 NovelForge AI 的关键借鉴建议

1. **引入一站式小说专项工具箱 (Novelist Toolbox)**：
   - 将现有零散的 AI 动作（顺势续写、场景五感、内心微表情等）整合为“起名/脑洞/总纲/分卷/章纲/开篇/正文/润色”的全生命周期专项工具卡片；
   - 工具箱与正文编辑器直接联动，生成结果支持“采纳并存入设定集”、“插入正文”或“存为历史版本”。
2. **构建本地优先的 Workflow Engine**：
   - 设计轻量级、无依赖、可在 Tauri 2 + SQLite 本地闭环运行的工作流引擎；
   - 支持可视化定义小说创作步骤、模型参数、输入表单与变量传递；
   - 提供分步执行、断点保存与用户人工原地修订能力。
3. **增强设定集的手动精准关联**：
   - 在多 Agent 创作或单步生成时，除现有的五层长期记忆自动装配外，提供一个直观的“关联设定选择器”，允许作者一键勾选特定角色、特定规则或特定历史章节注入上下文。
