## 1. 核心功能盘点矩阵

| 功能模块 | 对应路径 / 标识 | 证据级别 | 功能描述与实现机制 |
| :--- | :--- | :--- | :--- |
| **书籍与分卷管理** | `/books`, `/chapters/:id/:explode?` | [FACT-SOURCE] | 小说书籍创建、多卷组织、章节列表与爆更/分章视图 (`explode`) |
| **剧本与拆书** | `/scripts`, `/books/scripts` | [FACT-SOURCE] | 针对网文或剧本的拆解分析，支持将热门爆款提取为故事节拍公式 |
| **工作流列表与管理** | `/workflow/list` | [FACT-SOURCE] | 展示预置与用户自定义工作流，支持搜索、上锁/解锁、启用/禁用、权限控制 |
| **工作流编排器** | `/workflow/create`, `/workflow/edit/:id` | [FACT-SOURCE] | 支持多步骤定义、标题描述设置、输入表单（单选/多选/输入框/可选）、变量引用 |
| **工作流执行引擎** | `/workflow/execute/:runId`, `/workflow/run/:id` | [FACT-SOURCE] | 支持一键自动跑完、分步人工推进、从失败处继续恢复、输出原地编辑、结构化结果展示 |
| **成组批量执行** | `/workflow/execute-group/:groupId` | [FACT-SOURCE] | 多章节或多任务并行/成组批量推进执行 |
| **工作流测试** | `/workflow/test` | [FACT-SOURCE] | 单步骤独立调试与参数沙盒测试 |
| **设定集：角色卡** | 关联角色 | [FACT-SOURCE] | 角色姓名、外貌、性格、动机、金手指、生平；支持自动提取与步骤关联 |
| **设定集：词条卡** | 关联词条 / 关联知识卡 | [FACT-SOURCE] | 门派、地理、战力体系、法宝、专有名词；支持作为变量注入各创作步骤 |
| **上下文挂载** | 关联章节 / 关联备忘录 | [FACT-SOURCE] | 在工作流步骤中显式选择前序历史章节、当前章纲或灵感随手记 |
| **快捷动作与追问** | `/shortcuts/select`, 追问 | [FACT-SOURCE] | 针对正文选区的定向追问、润色、改写、扩写、续写 |
| **多模型支持** | DeepSeek, Kimi, Claude 等 | [FACT-SOURCE] | 在执行界面支持针对不同步骤切换模型或采用统一预设 |
| **社区与案例** | `/forum`, `/case/:id`, `/lesson/:id` | [FACT-SOURCE] | 用户分享工作流、实操教程、案例拆解与作者交流社区 |

## 2. 小说专项生成器全景（按创作生命周期划分）

### 2.1 构思与立项期
1. **书名生成器**：根据题材、受众、核心金手指生成爆款吸睛书名；
2. **简介生成器**：生成符合网文主流站点（番茄双钩子、起点三段式）的悬念简介；
3. **题材与核心脑洞**：设定核心金手指（系统、签到、长生、加点、科技文明等）与主要矛盾；
4. **力量体系与世界观法则**：输出境界划分、等级突破条件、势力地缘格局。

### 2.2 策划与人设期
1. **核心主角人设**：外貌特征、性格底色、核心动机、反差萌、金手指机制、禁忌底线；
2. **关键配角与反派群像**：师傅领路人、宿命对手、打脸反派、红颜知己、势力长辈；
3. **门派与地理词条**：宗门规矩、宗主长老名讳、禁地险峰、天材地宝产地。

### 2.3 大纲与节奏规划期
1. **百万字总纲**：按起承转合或阶段副本划分主线；
2. **分卷规划**：每卷核心副本高潮、目标达成奖励、卷末悬念转折；
3. **章节细纲（章纲）**：单章字数规划、进场冲突、推演展开、爽点释放、章末钩子。

### 2.4 正文创作与精修期
1. **黄金前三章开篇**：以极致节奏呈现金手指激活与首个危机打脸；
2. **正文续写与扩写**：根据细纲节拍生成 2,000~4,000 字正文；
3. **对话精修与微表情**：提升对话张力，去除 AI 译制腔与说教感；
4. **场景描写加深**：五感强化（视觉光影、声音动静、气味触感）；
5. **AI 追问与局部定向修改**：针对指定段落进行情节微调。
