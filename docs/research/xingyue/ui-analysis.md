# 星月写作 UI 交互与布局分析 (ui-analysis.md)

- **研究日期**：2026-10-14
- **证据来源**：公开 Web 前端布局 CSS/JS 与实测交互

---

## 1. 整体界面架构与功能分区

星月写作的 UI 体系呈现典型的“三段式”与“工作流主控台”两种主要视图：

### 1.1 经典小说编辑器模式
1. **左侧目录导航**：
   - 书籍总览、分卷折叠树、章节列表（含字数徽章）；
   - 设定集快捷入口（角色卡、词条库、备忘录）。
2. **中间沉浸编辑区**：
   - 极简富文本编辑器，工具栏集成中文字数统计、排版、纸张背景切换；
   - 选中正文触发悬浮工具条（续写、扩写、改写、追问、添加至设定）。
3. **右侧 AI 智囊面板**：
   - 提供快捷生成器选项卡（大纲、人设、正文、拆书）；
   - 对话与结果暂存区，支持一键“插入光标处”、“追加到末尾”或“替换选区”。

### 1.2 工作流专属执行看板模式 (`/workflow/execute/:runId`)
1. **顶部进度条与全局控制**：
   - 展示步骤流程面包屑（如：① 创意输入 -> ② 大纲规划 -> ③ 细纲拆解 -> ④ 正文生成）；
   - 右上角配备【一键执行】、【分步执行】、【停止运行】与【模型选择】。
2. **垂直步骤流式卡片**：
   - 每个步骤为一张独立的卡片；
   - 卡片左侧标注序号与状态指示器（待执行 / 执行中 / 已完成 / 失败）；
   - 卡片主体为输入表单与输出内容区域，具备【编辑输出结果】与【引用前面步骤变量】按钮；
   - 底部提供【从失败处继续执行】。

---

## 2. 界面交互亮点与用户体验评价

1. **结构化卡片与流式反馈**：
   - AI 执行时卡片内部逐字流式打印，同时支持随时中断；
   - 结构化结果（如分段、列表、关键要素标签）直观呈现。
2. **低心智负担的变量引用**：
   - 步骤配置中无需编写代码，通过可视化下拉菜单即可插入 `{{前面步骤输出}}` 或关联已有设定。
3. **安全容错机制**：
   - 生成内容默认不直接覆盖正在编辑的章节，必须由用户审阅确认后合并入正文。
