# 星月写作研究局限性与待验证猜测 (limitations.md)

- **编制日期**：2026-10-14
- **状态**：明确记录未经证明的猜测与边界

---

## 1. 当前研究的局限性

1. **未获授权的云端私有接口**：
   - 本次研究严格遵循合法与道德准则，未对其付费 API、云端服务端调度算法进行探测或抓包；
   - 云端后端的任务队列内部实现（如是否基于 Redis/Celery/Temporal/BullMQ）属于 [HYPOTHESIS] 待验证猜测，不影响我们在本地桌面独立设计并实现相同工作流能力。
2. **商业提示词库的未公开性**：
   - 官方与社区共享的几十万付费提示词具体细节未作抓取，我们重点关注其“提示词产品化设计模型”（分类体系、变量槽位、动态上下文注入与模型适配），通过为 NovelForge AI 打造本地可配置提示词工作室来达到更优效果。
3. **客户端运行**：
   - 星月写作主要运行形态为 Web SaaS 及基于 Capacitor 的移动端包装应用，本地未发现独立编译的 C++/Rust 原生客户端。

---

## 2. 待验证猜测清单 [HYPOTHESIS]

- **猜测 1**：云端角色提取是基于正则规则库还是轻量级 LLM 单次抽取？（推断为后者，即调用小模型执行命名实体识别与设定沉淀）
- **猜测 2**：知识库关联在云端是否具备向量检索（Vector Embedding）？（公开功能中更强调“显式勾选词条与角色”，推断为结构化关键词精准匹配 + 可选向量召回）
