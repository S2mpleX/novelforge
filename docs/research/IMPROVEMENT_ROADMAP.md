# 候选能力多维评估与升级路线图 (IMPROVEMENT_ROADMAP.md)

- **评估日期**：2026-10-14
- **评估标准**：
  - 价值分 (Value, 1~5)：对小说创作者创作体验与产出质量的改善程度
  - 架构契合度 (Architecture Fit, 1~5)：对当前 Tauri 2 + SQLite 架构的兼容性与低侵入性
  - 风险控制 (Risk Control, 1~5)：数据迁移、许可证与稳定性风险（5 为风险极低）
  - 成本复杂度 (Feasibility, 1~5)：开发与测试落地可行性（5 为容易落地且可控）
  - 综合指数 = (价值 × 0.4) + (契合度 × 0.3) + (风险控制 × 0.15) + (可行性 × 0.15)

### 2.1 P0 核心功能（首选切片，最高优先级）
- **目标**：彻底解决作者“如何高效写好一本书”的创作闭环问题。
- **包含能力**：
  1. **一体化小说专项工具箱 (Novelist Toolbox)**：提供从“起名/简介/脑洞/金手指/力量体系/黄金开篇/分卷总纲/单章细纲/正文写作/对话润色”的全套专项生成器，直接内嵌于工作台，生成结果支持一键存为正式角色卡、正式设定、正式章节或草稿版本；
  2. **设定集上下文选择器 (Context Picker)**：在任何生成器或 AI 对话中，提供轻量直观的抽屉/下拉选择器，作者可一键勾选当前作品中的核心角色、世界观规则、前置历史章节与备忘录，精准注入生成上下文；
  3. **轻量级本地工作流执行器 (Workflow Engine MVP)**：支持将“脑洞 -> 设定 -> 章纲 -> 正文 -> 审校”串成连续可控的任务流水线，提供“分步执行”与“中间输出原地编辑”。

### 2.2 P1 重要增强功能
- **审稿仲裁与修订采纳**：在现有审稿报告基础上，增加“标记误报”与“采纳生成 Diff 替换正文”；
- **提示词工作室**：支持按玄幻、都市、科幻、悬疑分类选择预设，支持作者保存自定义模板；
- **作者文风档案**：通过小采访或样例段落提炼作者笔触特征，注入 System Prompt。

### 2.3 P2 高级与扩展能力
- **多 Agent 独立网关绑定**：各 Agent 独立配置模型与 API URL；
- **Docking 新增专属预设**：“小说构思工坊”与“工作流流水线”两套全新工作区。
