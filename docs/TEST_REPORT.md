- **数据结构安全与生命周期操作**：
  - **章节拆分 (Split Chapter)**：基于字符偏移精确截断正文，自动为原章节创建历史版本快照，新章节继承原章节层级位置并自动重排后继章节序号，正文零丢失；
  - **章节合并 (Merge Chapters)**：将源章节正文自动换行拼接到目标章节末尾，源章节下全部场景重新归属至目标章节，源章节关联的剧情矩阵引用采用 `UPDATE OR IGNORE` 平滑转移至目标章节并清理孤儿节点，剧情引用零破坏；

  - **层级重编号 (Renumber Hierarchy)**：支持全书全局连续编号或按卷独立编号，自动规范化章节与场景 sequence 序号。
- **多 Agent 创作上下文递归组装 (`assemble_hierarchical_creation_context`)**：
