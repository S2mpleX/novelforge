# Humanizer · 中文长篇小说人情味与去 AI 味润色指南

本技能专门用于指导中文长篇小说的**文学化润色、彻底剔除大模型 AI 腔调、去除策划与系统设定外露，以及打造自然生动的人性化叙事与角色对白**。

---

## 一、核心原则：三大纪律与八项注意

### 1. 彻底斩断“AI 翻译腔”与空洞概括（Show, Don't Tell）
- **禁止说明文式转折**：严禁出现“首先”、“与此同时”、“这代表着”、“不仅如此”、“总的来说”、“毫无疑问”、“不得不说”等议论文行文方式。
- **禁止上帝视角虚假总结**：严禁写“殊不知，命运的齿轮已然开始转动”、“此时的他还不知道自己将面临什么”。
- **具象化物理细节替代情绪宣告**：
  - ❌ 错误（AI味）：“他感到极度的愤怒与屈辱，胸中翻江倒海，嘴角扯出一抹冷笑。”
  - ✅ 正确（Humanizer）：“他死死咬着后槽牙，牙龈渗出一股铁锈味，右拳在袖中攥得骨节发白，青石板地面被硬生生踩掉一层薄灰。”
  - ❌ 错误（AI味）：“两人之间建立起了一种不可言说的深厚羁绊与默契。”
  - ✅ 正确（Humanizer）：“篝火噼啪爆开一粒火星，他没抬头，顺手把烤透的干粮掰下一半递过去；对方接得自然，连谢字都没多说一句。”

### 2. 严厉禁绝设计与系统术语外露（No Meta Leakage）
- 除非是带有特定第四面墙的“数据流系统文”，否则正文、心理描写与角色对白中**严禁出现任何策划与代码痕迹**：
  - 严禁词汇：“Flag”、“回收”、“阶段目标”、“核心驱动力”、“结算”、“战力数值”、“剧情推进”、“设定”、“逻辑矛盾”。
- 每一个角色的反应必须根植于其**当下生理状态、认知边界、阶层地位与生存欲望**，拒绝沦为推剧情的工具人。

### 3. 对白的生活化、留白与呼吸感
- **拒绝大段宣讲式独白**：人在真实交流中极少一口气背诵两百字的背景设定。
- **潜台词与身体微动作**：
  - 真正的交锋往往在言外之意。说话时伴随眼神偏移、点烟、抚平袖口褶皱、端茶不饮等微动作。
  - 允许答非所问、犹豫、反问、话留半句。

## 二、高频 AI 套话黑名单与替换指南

| 常见 AI 套话 / 滥用句式 | 缺陷剖析 | Humanizer 优化示范 |
| :--- | :--- | :--- |
| **“仿佛 / 宛如……”** | 泛滥的廉价比喻，削弱在场感 | 直接陈述物理事实，或用特定触感、气味、声响落地 |
| **“嘴角勾起/扯出一抹微笑”** | 网文大模型极其高频的脸谱化肌肉抽搐 | 用眉骨微动、垂下眼睑、嗤笑出声或手指叩桌替代 |
| **“眼中闪过一丝不可察觉的……”** | 既“不可察觉”，叙述者又如何得知？典型自相矛盾 | 写眼神停留的时长、瞳孔收缩、或故意避开的视线 |
| **“深吸了一口气”** | 每到紧张处必深呼吸，极其公式化 | 写喉结滚动、胸膛剧烈起伏、或屏住呼吸听窗外风声 |
| **“空气仿佛凝固了”** | 偷懒的环境描写套话 | 写香炉青烟笔直向上不散、或是远处更夫打更的一声梆子响 |
| **“一时间，众人……”** | 粗暴的群像动作同步，失真 | 分层描写：有人慌乱后退撞翻凳子，有人手按刀柄，有人借故低头看酒碗 |
| **“不得不承认 / 毫无疑问”** | 议论文腔调，出戏 | 删去！直接写事实与人物内心的直观判断 |

## 三、文风叙事指纹与流派适配规范

1. **玄幻 / 修仙流派**：
   - 戒除西幻式长定语翻译腔；
   - 意象取自中式古典物象（松石、炉火、霜雪、雷劫、古剑铭文）；
   - 对话讲究辈分、道心与命数，杀伐果断而不做作。
2. **都市 / 现实流派**：
   - 强调市井烟火气、方言口癖与人情世故；
   - 道具需具象（特定品牌的烟盒、电瓶车的电量格、街角油条摊的油烟味）。
3. **悬疑 / 惊悚流派**：
   - 笔触冷峻克制，拒绝一惊一乍的感叹号；
   - 放大生理直觉（后背汗毛直立、皮肤表面的冰凉感、呼吸节奏的紊乱）。

## 四、自动化工作流指令

当在 NovelForge AI 中执行文学润色与去 AI 味时，遵循以下执行流水线：

1. **检测 (Audit)**：调用 `HumanizerEngine.detectClichés(text)` 标记高频套话与假大空断句；
2. **定音 (Voicing)**：提取当前小说作品的 `VoiceProfile`（时代口吻与叙事指纹）；
3. **精修 (Polishing)**：以具象动作代替形容词，打散欧化长句，补齐微表情与声色留白；
4. **守卫 (Verification)**：运行自动化质检测试，验证 Canon 设定完整性与因果锁闭。
