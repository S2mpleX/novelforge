# 可复制的调用提示词

## A. 从头创作：先做结构，再写正文

请调用 `/story-architect`。我希望创作一部【题材】小说，核心情绪是【目标情绪】，我最不接受的缺点是“匀速流水账、公式化反转、情绪靠旁白解释、结尾平淡”。先交付三个**因果结构不同**的故事方案，而不是三个换皮设定；每个方案说明主角真正的欲望、内心矛盾、关键错误选择、不可逆后果以及可以被前文公平支撑的结局。不要写正文，不要套固定三幕百分比。

## B. 用结局反推前文

请调用 `/ending-forge`，基于已选方案设计三个在价值上不同的结局，而不仅是死亡人数不同。选出最能兑现主题、代价最有说服力的方案。倒推需要提前建立的人物关系、物件和事实；核查是否靠巧合、反派降智或新规则救场。结局要有明确后果，允许克制的收尾，不要强行写金句。

## C. 写一章但不要「均匀加速」

请调用 `/scene-dramaturge`，根据上章角色状态、未解决问题和本章必要转变，先选择本章的节奏功能（蓄力、裂变、余波、关系推进、信息重估、快速行动、静默反衬之一或其组合），给出两个**不同节奏策略**，择优写作。写作时不要求每 500 字一个冲突、不要求章末强制悬念。冲突优先来源于角色价值与有限条件下的选择，而非突然出现的外部灾难。

## D. 对已有章节做真正的「冷读」

请在一个**不继承作者分析、大纲和改稿理由的新 Agent 会话**里调用 `/cold-reader`，只提供我要分析的正文和最基本的类型信息。标明你在哪一段失去兴趣、何时预见结局、哪里情绪被解释而非体验、角色决定是否可信。必须用原文位置/短引文作证据，给出不超过三项优先修改建议。先诊断，不要自行重写。

## E. 改写某段平淡剧情

下面是我的原文：【粘贴片段】。
请分别回答：
1. 这段结束时，人物、关系或读者认知发生了什么实际变化？
2. 哪些句子只是在解释作者希望读者产生的感情？
3. 若删掉一半铺垫，损失的到底是信息还是情感重量？
4. 请提供三种改造路线：低调蓄力、价值冲突、迟到的情绪回响。不要新增违反既定规则的情节。
然后只执行我指定的一条路线，保留事件逻辑与人物动机。

## F. 在 Antigravity 中改造现有 V2.0 小说生成工具

你正在为我的多 Agent 连载小说生成工具增加“戏剧节奏引擎”，不要推倒现有数据库、记忆引擎、角色设定和可编辑大纲。

先审计现有写作流程、提示词、状态字段和日志，再以最小侵入方式加入四个可配置阶段：

1. Story Architect：负责跨章因果与人物选择；输出可编辑的结构方案，不写正文。
2. Scene Dramaturge：负责单章的具体导演方案和正文；支持静场、余波与非均匀节奏，不强制每章反转。
3. Ending Forge：从主题、代价和已有伏笔反推高潮与结局，标记哪些证据已真实进入正文。
4. Cold Reader：在独立模型上下文中只读正文，禁止加载作者的隐藏意图或先前创作理由；返回“证据定位→读者反应→问题成因→最小修复建议”，不得默认改写。

数据至少记录：scene_id、参与人物、进入/离开时的状态、场景功能、读者已知信息、角色已知信息、关键选择、长期后果、伏笔证据及回收状态。提供场景级和章节级节奏可视化，但统计不得充当小说好坏的硬阈值。

在 UI 中新增：原文 vs 修改版对比；读者卡顿位置；各阶段独立开关；仅重写选中片段；采纳/驳回建议；生成结果的版本记录和回滚。不要一次性重写全书。

验收测试：用同一故事种子分别运行“当前工作流”和“新工作流”，盲评前三章与最后一章。检查人物决策可信性、因果链、机械钩子、重复场景功能、高潮伏笔兑现及结尾余韵。若新流程只提高反转数量却降低逻辑或情绪可信度，判定失败。先输出可实施的改造计划、相关文件清单、数据变更和测试方案，然后再开始修改代码。
