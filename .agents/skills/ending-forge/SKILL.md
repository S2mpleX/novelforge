# Ending Forge：有代价的结局

## 核心标准
好的结局不是“最后有人死了”或“最后一句很漂亮”。它应该兑现主角一路以来的价值困境，使既有事实获得更深意义，并留下人物无法轻易撤销的后果。

## 先读输入
只依据已提供的世界规则、人物关系、伏笔、未解决的承诺和事件。分清“作者计划过”和“正文已经写出来”。后者才能算公平伏笔。

## 结局候选
至少生成三种**价值判断不同**的结局路线，而不是同一结局替换伤亡名单：
- 苦涩兑现：外部目标获得，主角失去以往定义自己的信念/关系。
- 克制和解：外部结果可能失败，但人物终于完成以前做不到的决定。
- 延迟认知：多年以后，一个早已存在的细节使过去的选择产生第二重理解。必须确保线索在前文可信存在。

不用强制选择上述三型；按题材改造，不把它们当格式或配额。

## 逆向验证
1. 主角是否亲自作出关键决定？纯事故不能替代人物弧光。
2. 代价是什么？对谁有长期影响？若次日可以完全复原，不是真正的代价。
3. 反转是否**重新解释旧信息**，而不是突然增添新机制？
4. 关键选择需要的动机、能力、信息和关系是否在正文中建立？
5. 最后的情绪是经由具体的动作/物件/缺席产生，还是由旁白宣布“所有人泪流满面”？
6. 可否在高潮后给读者半步安静，让情绪自行抵达？也可在不可逆瞬间切断，不必二者兼具。
7. 是否为了催泪而故意令人物行为失真、消耗无意义死亡？若是，退回重构。

## 输出要求
提供三案对比：主题兑现、角色能动性、所需伏笔、逻辑风险、可能的读者余韵；选一个推荐案并给出“结局倒推铺垫表”，写明哪个前文场景需要放入什么可被误读的证据。不允许凭空声称已有伏笔。

若用户要求写结局正文：给出两种收束方式（迅速截断 / 短暂余波），可以只提供推荐稿正文，避免用“这注定是一场……”式旁白和重复主题金句。
