- 关键发现：
  1. **Tauri v2 原生对话框隐患（高危，待真机验证）**：60+ 处 `alert/confirm/window.prompt`，但 Cargo.toml 未引入 tauri-plugin-dialog；Tauri v2 默认不实现 JS 对话框，桌面端这些交互可能静默失效（浏览器预览模式下正常，故测试套件测不出）。

  3. 40+ 个模态框各自实现遮罩（bg-black/40~60、blur、动画时长不一），无共享 Modal 基元；建议收敛为统一 Modal/Drawer 基元。
  4. 版本号不一致：Header 硬编码 v2.5、编辑器空态 V2.0、package/tauri 2.3.3、PROJECT_STATE 声称 V2.6.4、CHANGELOG 最新 2.3.0；已有 check:version 脚本可复用。
  5. 暗色模式下 4 种纸张主题（宣纸/竹纸/牛皮/水墨）被 CSS 强制统一为 midnight 渐变，纸张选择在暗色下失去差异。
  6. 密度偏高：text-[10px]/[11px] 大量使用；muted-foreground #786f65 on #f4efe6 对比度约 4.3:1，低于 WCAG AA 4.5。
- 优点（结论）：暖纸 parchment 美学体系完整且有辨识度（SVG 噪声纸纹、印章朱砂、衬线正文）；Header 六步创作流水线 stepper + Dashboard 卡片形成强心智模型；自研 docking 工作台（splitter/tab/floating/maximize）完成度高；明暗双主题完整。

## P1 落地：语义设计令牌体系 + 废除暗色 !important 补丁（ADR-039 / PROJECT_STATE §3.13）
- 实装：App.css 新增 Tailwind v4 `@theme inline` 令牌（--wf-* 双取值变量 → bg-canvas/surface/surface-2/surface-3/hover:bg-surface-3-hover/text-ink/text-ink-2/text-primary/border-line + shadcn 兼容别名）；codemod 迁移 3275 处 / 79 文件（角色感知+变体感知：dark: 专用 hex 不动、hover 映射提亮令牌、透明度后缀保留、text-amber-700/800/900→text-primary）；删除 ~105 行暗色补丁，仅留 2 个低频残留色（#435447/#5c432d）。
- 重大发现（潜在 bug 修复）：旧补丁的无层级 `!important` 一直在覆盖组件显式 `dark:bg-[#hex]` 工具类（Header 暗色被压成 #282835 而非设计值 #1a1714）；bg-card/text-foreground 等类此前无工具类定义完全失效（WorkflowPanel/InlineDiffViewer 渲染无背景）——令牌体系顺带修复。
- 验证方法（可复用）：playwright-core + 本机 chromium 走查截图；Pillow（已装入 managed python venv：C:/Users/xiaoyong/.workbuddy/binaries/python/envs/default/Scripts/python.exe）做像素 diff + 网格热点定位 + 颜色对采样；浏览器 page.evaluate 读 computed style 核对暗色意图值；page.hover 验证 hover 令牌。
- 结果：tsc 0 错误、vite build 5.16s 通过、9 视图亮色差异 ≤17/255（文本统一偏移，不可感知）、暗色差异均为修复项、hover 提亮 #323244 生效。
- 遗留（下一轮 P1/P2）：~800 处低频 hex 未迁移（渐变 from/to、状态色、纸材色）；40+ 模态框收敛共享 Modal 基元；版本号五处不一致；暗色下 4 纸张主题差异丢失；10px 字号与 muted 对比度。
